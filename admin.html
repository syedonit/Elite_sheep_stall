⚙️ Firebase Setup Guide

To enable photo uploads and live price updates on your website, you need to connect Firebase (free by Google). Follow these steps once — takes about 10 minutes.

1

Go to Firebase Console

Visit console.firebase.google.com → Sign in with your Google account → Click "Add project" → Name it seasonal-sheep-stall → Continue → Disable Google Analytics → Create project

2

Enable Firestore Database

In left sidebar → Firestore Database → Create database → Choose "Start in test mode" → Select region asia-south1 (Mumbai) → Done

3

Enable Storage (for photos)

In left sidebar → Storage → Get Started → Test mode → Next → Done

4

Get your Config Keys

Click ⚙️ Project Settings → "Your apps" section → Click "Web" icon (</>) → Register app as sheep-stall → Copy the firebaseConfig object

It looks like this:

// Replace these with YOUR actual values from Firebase
apiKey: "AIzaSy...",
authDomain: "seasonal-sheep-stall.firebaseapp.com",
projectId: "seasonal-sheep-stall",
storageBucket: "seasonal-sheep-stall.appspot.com",
messagingSenderId: "123456789",
appId: "1:123:web:abc123"
5

Paste config in admin.html & index.html

In both files, find the section marked PASTE YOUR FIREBASE CONFIG HERE and replace the placeholder values with your actual Firebase config keys. Then re-upload both files to GitHub.

6

Done! 🎉

Come back to this Admin Panel → Animals tab → Add animals with photos, prices & weight. They'll appear live on seasonalsheep.in instantly!
